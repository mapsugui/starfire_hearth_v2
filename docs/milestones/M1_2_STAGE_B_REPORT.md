# M1.2 Stage B — shared city streets

Status: implemented and locally revalidated on the existing M1 lineage.
Prepared 3 October 2026. Owner visual/playtest acceptance remains open.

## Result

New campaigns use one shared street network instead of separate paths from a
fixed hub. Streets join the external frontage of actual building assemblies;
the reclaimed hull uses its side airlock. The planner uses production footprint
bounds, terrain grades and supported platforms, joins nearby entrances to the
existing network, merges duplicate edges and supplies visible junctions.
Smoothing removes unnecessary lattice bends while preserving clearance,
terrain limits and other street intersections.

Existing campaigns keep their old road recipe until **Update city roads** is
selected in scene tools. That action changes only presentation: terrain,
appearance profiles, anchors, buildings, orders and gameplay checksums stay
unchanged. The versioned component survives save/load; unsupported future
recipes fall back without being overwritten. New colony identities are added
without replacing the existing recipe.

Routes rebuild when relevant terrain, completed assemblies, tier, architecture
or recipe changes. Selection, queues and ordinary inspector refreshes reuse
the network. Impossible access is returned explicitly; scene tools report
that some buildings have no supported road access. Legal construction remains
usable. This is automatic visual access, not a new road-building/traffic rule.

## Measured cost and remaining work

The production fixtures took about **0.62–0.69 seconds** to create a network
in this software-rendered cloud run; cached refreshes reuse it. This initial
CPU work can cause a visible pause when a large city changes. It is recorded
as quality-first performance debt, not hidden behind an asserted frame budget.
Worker scheduling and additional planner optimization remain follow-up work.

The planner is deterministic and terrain-aware, but it is a bounded heuristic,
not a globally optimal road solver. Bridges and player-directed street editing
are outside this checkpoint's agreed scope. Owner review should assess visual
coherence in naturally grown cities as well as the explicit catalog fixtures.
No branch, commit, push, tag or M1.2 release was created by this stage.
